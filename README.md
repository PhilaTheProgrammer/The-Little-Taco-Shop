1. PROJECT OVERVIEW
The purpose of this web app development project is to give a small business called "The Little Taco Shop" some online presence and marketing. It wll improve marketing and increase exposure to the market. It will allow users to view the Taco Shop and proceed to contact The Little Taco Shop. It is built with a clean UI and responsive design.
